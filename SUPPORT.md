# Support

## Support channels

### Documentation

Start with the project documentation:

- [Documentation site](https://graphiks-org.github.io/kadre/)

### GitHub Issues

Use GitHub Issues for:

- bug reports
- feature requests
- technical questions tied to the current repository state

https://github.com/Graphiks-org/kadre/issues

### GitHub Discussions

Use GitHub Discussions for:

- general questions
- design ideas and suggestions
- community feedback around the library foundation

https://github.com/Graphiks-org/kadre/discussions

### Email

For sensitive inquiries:
[contact@ygdrasil.com](mailto:contact@ygdrasil.com)

## Before opening an issue

1. Check the documentation site first.
2. Search existing issues and discussions.
3. Use the appropriate issue template.
4. Include reproduction steps or the exact command that failed when relevant.
